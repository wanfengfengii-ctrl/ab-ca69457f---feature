# 复合材料射线检测 · 四向投影重建复核台

对复合材料截面做四向射线扫描后，只保留各扫描线穿过的夹杂物数量（投影）。
本工程提供 React + FastAPI 全栈复核台：检测员在浏览器中编辑四向投影与已知单元，
通过真实 API 发起完备重建，并在网格中切换核对歧义见证——局部填格可能满足横纵
投影、却在斜向投影上产生无法察觉的伪截面，因此重建必须同时约束四个方向。

## 问题定义

- 截面为 **4~12 行 × 4~12 列** 的二值网格（1=夹杂物，0=基材），行列均从 **0** 编号。
- 四向投影（均为非负整数，且不超过对应扫描线的单元数）：
  - **行投影**：自上而下，长度 = 行数；
  - **列投影**：自左向右，长度 = 列数；
  - **对角投影**：按 **(行 − 列)** 差递增，长度 = 行数 + 列数 − 1
    （首条为右上角单元 `(0, C−1)`，末条为左下角单元 `(R−1, 0)`）；
  - **副对角投影**：按 **(行 + 列)** 和递增，长度 = 行数 + 列数 − 1
    （首条为 `(0, 0)`，末条为 `(R−1, C−1)`）。
- **已知单元**：检测员已确认的单元取值（0 或 1），不得重复或冲突。
- **连续夹杂体约束（可选）**：金相确认夹杂物属同一连续夹杂体时启用
  （请求字段 `"connected": true`，省略视为关闭）。启用后，任一有夹杂的
  返回网格中全部值为 1 的单元必须**仅经上下左右相邻**的值为 1 单元互达，
  **对角接触不算连接**；没有夹杂物的全 0 网格仍可成立。该约束与四向投影、
  已知单元及字典序见证排序在**同一次完整求解**中处理（并非先取旧见证再
  事后筛除），无满足连通性的方案时返回 `no_solution` 与空网格。
- 后端须完备判定 **无解 / 唯一解 / 多解**；有解时按 **行优先位串、0 先于 1**
  的字典序返回最小的一个（唯一）或两个（多解）见证。

## 快速开始（Docker Compose）

```bash
docker compose up --build        # 启动 web + api（verify 也会跑一次验收后退出）
```

- Web 界面：http://localhost:8080 （可用 `WEB_PORT` 环境变量改宿主机端口）
- API 文档：http://localhost:8000/docs （可用 `API_PORT` 环境变量改宿主机端口）

```bash
WEB_PORT=9000 API_PORT=9001 docker compose up --build   # 自定义宿主机端口
```

`api` 与 `web` 均配置了健康检查（`docker compose ps` 可见状态）：
API 暴露 `GET /api/health`，Web 暴露 `GET /healthz` 并反向代理 `/api/*` 到 API。

## 一次性验收服务 verify

`verify` 是 Compose 中的一次性验收服务：等待 API 与 Web 健康后执行 55 项
端到端核验（含 4×4 暴力枚举独立复核、字典序检查、已知单元约束、14 类非法
输入的可定位 422、8×8/12×12 见证校验，以及连续夹杂体约束的连通、对角断开、
无夹杂、旧接口兼容四类场景），随后自行退出并以退出码报告结果：

```bash
docker compose up --build --exit-code-from verify verify
echo $?          # 0 = 验收通过，1 = 存在失败项
docker compose up -d web api   # 验收后正常启动应用
```

## API

### `POST /api/reconstruct`

请求体：

```json
{
  "rows": 6, "cols": 6,
  "row_sums": [3, 2, 4, 2, 2, 4],
  "col_sums": [1, 3, 2, 3, 3, 5],
  "diag_sums": [1, 1, 2, 1, 3, 4, 2, 1, 1, 1, 0],
  "antidiag_sums": [0, 1, 1, 2, 1, 3, 3, 1, 2, 2, 1],
  "known_cells": [{"row": 0, "col": 1, "value": 1}],
  "connected": false
}
```

`connected` 可省略（等同 `false`）；为 `true` 时要求所有 1 单元四邻连通
（对角不连接），全 0 网格不受影响。

响应（200）：

```json
{
  "status": "unique | multiple | no_solution",
  "rows": 6, "cols": 6, "connected": false,
  "solutions": [{"grid": [[0, 1, ...], ...], "bits": "0101..."}],
  "elapsed_ms": 17
}
```

- `unique` → 1 个解；`multiple` → 字典序最小的 2 个解；`no_solution` → 空列表
  （启用 `connected` 后若不存在四邻连通方案，同样返回 `no_solution` 与空列表）。
- 输入非法（长度不符、投影超过线长、已知单元重复/冲突/越界等）返回 **422**，
  `detail` 为可定位错误列表：`[{"loc": "row_sums[2]", "msg": "值 9 超过该线单元数上限 6"}]`。
- 投影总和矛盾等"合法但不可满足"的输入返回 200 + `no_solution`。

## 求解方法（完备性说明）

后端使用 OR-Tools CP-SAT 约束求解器，**不使用贪心、随机搜索，也不会
"找到首解后推测唯一性"**：

1. 以 0/1 变量建模全部四向投影等式与已知单元约束；启用 `connected` 时
   在**同一模型**中加入连通编码（见下）；
2. 可行性判定 → 无解；
3. 将 144 位行优先位串切成 ≤60 位的块，逐块最小化"以块首为最高位的二进制
   整数"——每块的最优整数值与位型一一对应，逐位锁定后处理下一块，得到
   0<1 字典序意义下**确定的最小解**（与求解器内部启发式无关）；
4. 加入"至少一个单元不同"约束再次判定：不可行 → **唯一**（由 CP-SAT 给出
   不可行证明）；可行 → 在同一排除约束下再次分块最小化，得到第二小的解 →
   **多解**。

**连续夹杂体连通编码**（启用时在同一个 CP-SAT 模型内生效，四个求解阶段
全部携带，因此不存在"先取旧见证再筛除"）：

- 引入前缀或 `pref[i]`（位置 i 之前是否出现过 1），令行优先最早的 1 单元
  成为唯一根 `root`；全 0 网格没有根，仍可行；
- 每个 1 单元带层数 `lvl`，根为 0；非根 1 单元层数 ≥1，且必须存在一个
  **上下左右**（不含对角）相邻的 1 单元层数恰小 1；
- 沿层数严格递减必能到达唯一根，故所有 1 单元互达；反之任意四邻连通形
  都能以到根的最短距离为层数，编码既不排除任何连通形，也不放过断开形。

12×12 随机实例实测单次重建约 20~80 ms。

## 前端复核要点

- 网格行列从 0 编号，行/列投影输入框直接嵌在网格右侧与下方，两组对角投影
  按 `d=行−列`、`s=行+列` 逐线列于侧栏；
- **编辑已知单元** 模式下点击网格循环 `未知 → 1 → 0 → 清除`；
- 重建后 **逐线显示见证的实算和与目标值**（绿色 ✓ / 红色 ✗），编辑投影后
  徽标实时重算，便于复核员核对每条扫描线；
- 多解时用 **见证 1 / 见证 2** 标签页切换，两见证的 **差异单元以琥珀色高亮**，
  并列出全部差异坐标；
- 工具栏可勾选 **连续夹杂体约束**（四邻连通，对角不算）；每份见证旁显示
  **夹杂数量、连通团簇数、首个非主团簇坐标**（主团簇 = 含行优先最早夹杂物
  的团簇）；
- 勾选/取消约束或编辑任一输入后，旧见证立即清除；非法输入、无解或请求
  失败时也不会保留与当前条件不符的旧网格。
- 非法输入或无解时 **清除旧网格**，并给出可定位反馈（逐条 `位置：原因`，
  无解时附四组投影总和一致性排查线索）。
